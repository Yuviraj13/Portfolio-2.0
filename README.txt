YUVRAJ CHAUHAN — BUSINESS CENTRAL / AL PORTFOLIO

FILES
- index.html  : page content and project descriptions
- style.css   : responsive dark-theme styling
- script.js   : mobile navigation, reveal effects, active navigation and current year

RUN LOCALLY
1. Extract the ZIP folder.
2. Open index.html in a modern browser.
3. For local development, open the folder in VS Code and use Live Server if installed.

BEFORE PUBLISHING
1. In index.html, replace YOUR_EMAIL@example.com with your real email address.
2. Replace YOUR-LINKEDIN-SLUG with your LinkedIn profile slug.
3. Replace YOUR-GITHUB-USERNAME with your GitHub username.
4. Add your actual company name and employment dates in the Experience section, or remove the line that says company and dates can be added.
5. Add your college name and graduation year if you want these public.
6. Confirm every project description is accurate and only link code/screenshots you are allowed to share.
7. The portfolio does not include a real resume file or a backend contact form. Add those separately if needed.

CONTENT NOTES
- The project section is described as selected work and practice implementations; it does not claim that every project is a production deployment.
- The design uses Google Fonts from fonts.googleapis.com. The site still renders with fallback fonts if network access is unavailable.
- This is a static HTML/CSS/JavaScript site; no server is required for local viewing.
